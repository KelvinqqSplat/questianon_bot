# Anonymous Q&A Telegram Bot (questianon-style)

Готовый проект бота для анонимных вопросов на **aiogram v3**.

## Возможности
- Персональная ссылка `/link` вида `https://t.me/<your_bot>?start=ask_<token>`
- Приём анонимных вопросов и ответы на них
- Кнопка **✍️ Ответить** под вопросом
- Антиспам (рейтк-лимиты)
- Блокировка отправителей (адресат может заблокировать конкретного анонима)
- Жалоба админам (⚠️ Жалоба) + /broadcast для рассылки
- Статистика `/stats` для пользователя и `/admin` для админов
- Автоочистка старых тредов по сроку хранения
- Инлайн-режим: быстро поделиться своей ссылкой

## Быстрый старт
1. Создайте бота у @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запуск (long-polling):
   ```bash
   python -m src.main
   ```

## Переменные окружения (.env)
- `BOT_TOKEN` — токен от BotFather (обязательно)
- `ADMIN_IDS` — список админов через запятую (опционально)
- `DB_PATH` — путь к SQLite (по умолчанию `bot.db`)
- `RETENTION_DAYS` — хранение тредов в днях (по умолчанию 90)
- `RATE_LIMIT_COUNT` — сообщений в окне (по умолчанию 5)
- `RATE_LIMIT_SECONDS` — окно для лимита (по умолчанию 10)

## Docker
```bash
docker build -t anon-bot .
docker run --env-file .env --name anon-bot --restart=always anon-bot
```

## Приватность
Получатель не видит отправителя. Владелец бота технически может видеть ID в БД/логах — как и у любого телеграм-бота.


## Админ-панель
Команда: `/admin` (доступ только пользователям из `ADMIN_IDS`).

Возможности:
- 👥 Пользователи — список с пагинацией, карточка профиля (ID, username, имя, админ, статистика), глобальный бан/разбан.
- 🗂 Жалобы — просмотр последних жалоб с данными треда.
- 🧾 Логи — просмотр хвоста `logs/app.log` + возможность выгрузить файл.
- 📈 Статистика — сводка по пользователям, вопросам, жалобам.
- 📤 Экспорт users.csv — выгрузка CSV с пользователями.

Логи пишутся в `logs/app.log` с ротацией (до 3 файлов).
